# Lance Alexis Villanueva — Portfolio Website

A modern, high-performance developer portfolio built with **Vue 3 (Composition API)**, **Vite**, and **Tailwind CSS**.

## 🚀 Features

- **Header / Navigation:** Sticky glassmorphic navbar with active section detection, smooth scrolling, animated Dark/Light mode theme switch, and responsive mobile menu drawer.
- **Hero Section:** Profile photo integration, live "Student & Aspiring Developer" status indicator, glowing ambient backdrops, key metrics, and direct CTA actions.
- **01 — About Section:** Academic & student background narrative, core learning pillars, and interactive JSON profile terminal widget.
- **02 — Tech Stack:** Categorized technology badges strictly reflecting approved skills (HTML, CSS, JavaScript, PHP, Bootstrap, Tailwind CSS, Laravel, C++, Python, Java, MySQL, Figma, Git & GitHub Actions, Adobe Photoshop, Adobe Animate) with filter tabs.
- **03 — Contact:** One-click copy email feature, direct mailto button, and social links to Facebook, GitHub, Instagram, and Email.
- **Theme Switcher:** Animated dark and light theme toggle with persistent storage (`localStorage`) and smooth CSS transitions.
- **Footer:** Back-to-top button, quick social links, and copyright info.

## 🛠️ Tech Stack

- **Framework:** Vue 3 (Composition API with `<script setup>`)
- **Build Tool:** Vite
- **Styling:** Tailwind CSS + custom glassmorphism & transitions
- **Icons:** Lucide Icons (`lucide-vue-next`)

## 💻 Development & Build

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

## 🌐 Deployment

The project builds to the `dist/` directory and can be deployed directly to Vercel, Netlify, GitHub Pages, or any static hosting provider.
